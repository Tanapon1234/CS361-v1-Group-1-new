# ซ้อม Peer Test V2 (TC1–TC3) ก่อนรอบ 2 (#195)

ใช้กับเว็บที่ deploy แล้ว ไม่ใช่ localhost ทำตามลำดับแล้วกรอกผลในตารางท้ายไฟล์ เก็บภาพหน้าจอไว้ที่ `evidence/v2/peer-test/`

## เตรียมก่อนซ้อม

1. รัน migration บน Aurora (`backend/scripts/apply_migrations.py`, #198)
2. นำเข้าอาจารย์ V1 และข้อมูล demo ผ่าน API ที่ deploy แล้ว

   ```bash
   cd backend
   uv run python -m scripts.import_v1_lecturers --base-url <BackendApiEndpoint>
   uv run python -m scripts.seed_workload_demo  --base-url <BackendApiEndpoint>
   ```

3. `scripts/smoke-v2-backend-api.sh --save` ต้องผ่านทุกข้อ
4. เปิดเว็บ (Vercel) → เมนู "ระบบจัดการ" → "ผลงานรายปี"

## TC1: "อาจารย์คนนี้ทำอะไรบ้าง?"

| ขั้นตอน | ผลที่ต้องเห็น |
|---|---|
| เลือก อาจารย์ = ผศ.ดร.ประภาพร รัตนธำรง, ปีการศึกษา = 2567, หมวด = ทุกหมวด แล้วกดค้นหา | บรรทัดสรุป "พบผลงานของ ผศ.ดร.ประภาพร รัตนธำรง ในปีการศึกษา 2567 8 รายการ" |
| ดูผล | มีหลายหมวด: งานสอน, งานวิชาการ, งานบริหาร, งานบริการวิชาการ และส่วนผลงานตีพิมพ์ |
| ดูคอลัมน์ "รอบ" ทุกแถว | เป็น "รอบประเมินปีการศึกษา 2567" ทั้งหมด |

## TC2: "ขอเฉพาะงานวิจัยของปีนี้"

| ขั้นตอน | ผลที่ต้องเห็น |
|---|---|
| อาจารย์เดิม, ปี 2567, หมวด = 2. งานวิชาการ | "พบงานวิชาการของ ... ในปีการศึกษา 2567 3 รายการ" |
| ดูผล | มีแค่หมวด 2 (บทความ Q1 + นำเสนอผลงาน) และผลงานตีพิมพ์ปี 2567 (2024) 1 ชิ้น ไม่มีหมวดอื่น |
| เปลี่ยนปีเป็น 2566 | ได้ผลของปี 2566 เท่านั้น |

## TC3: "ไม่มีผลงาน หรือเราแค่หาไม่เจอ?"

| ขั้นตอน | ผลที่ต้องเห็น |
|---|---|
| อาจารย์ = ผศ.ดร.กษิดิศ ชาญเชี่ยว, ปี 2567, ทุกหมวด | "ไม่พบผลงานของ ผศ.ดร.กษิดิศ ชาญเชี่ยว ในปีการศึกษา 2567" และปุ่มปีที่มีข้อมูล 2568, 2566 |
| กดปุ่ม 2566 | เห็นผลงานปี 2566 ของกษิดิศ (ไม่ใช่ของคนอื่น) |
| อาจารย์ = ผศ.ดร.ฐาปนา บุญชู, ปี 2567, หมวด 2 | "ไม่พบงานวิชาการของ ผศ.ดร.ฐาปนา บุญชู ในปีการศึกษา 2567" + ลิงก์ "ดูทุกหมวดของปีนี้" |
| อาจารย์ = อาจารย์ปกรณ์ แววสว่างวงศ์, ทุกปี | "อาจารย์คนนี้ยังไม่มีภาระงานหรือผลงานตีพิมพ์ในระบบเลย" |
| ปิด backend หรือแก้ `BACKEND_API_BASE_URL` ผิดชั่วคราว (ทำใน preview deployment เท่านั้น) | กล่องสีแดง "โหลดผลงานไม่สำเร็จ ผลนี้ไม่ได้แปลว่าไม่มีผลงาน" ไม่ใช่ข้อความ "ไม่พบ" |
