## TC5: ลองทำสิ่งที่ไม่ควรทำได้

ผู้ทดสอบพยายามด้วยตัวเอง บันทึกว่าระบบกันหรือไม่ (ผ่าน = ระบบกัน)

- login เป็นอาจารย์ แล้วเปิด URL ของหน้า staff ตรง ๆ (เช่น `/manage/lecturers/new`) → ไม่มีฟอร์ม
- เปิดใบภาระงานของอาจารย์คนอื่นด้วย URL → กล่องแดง ไม่มีสิทธิ์
- ใช้ session ที่หมดอายุ (รอ > 1 ชั่วโมง หรือลบ cookie) → ถูกพาไป `/login` แล้วกลับหน้าเดิมหลัง login
- ใช้ `curl` ยิง API ตรงโดยไม่มี token → 401, ด้วย token ของอาจารย์ไปที่ endpoint ของ staff → 403 (`curl -H "Authorization: Bearer <ID token>" <BackendApiEndpoint>/api/v2/departments -X POST ...`)
- ส่ง header `X-Lecturer-Id` / `X-Dev-Roles` ไปที่ backend ที่ deploy → ถูกเมินเพราะปิดนอกโหมดพัฒนา (ต้องตั้ง `DEV_AUTH_HEADER_ENABLED=false` บน Lambda ก่อนทดสอบข้อนี้)
